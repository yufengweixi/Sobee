# Sobee

> 一个 Windows 桌面效率工具，将快捷启动、脚本执行和个人工具整合到一个面板中。

## 📖 简介

Sobee 是一款 Windows 桌面快捷启动工具。

它可以将常用的：

- 软件
- 文件夹
- 文件
- UWP 应用
- 网站
- 系统命令
- JavaScript 脚本
- HTML 工具

统一整理到一个悬浮面板中。

通过 **「类目 + 快捷方式」** 的方式管理，让常用工具更加集中，减少桌面和开始菜单中的查找操作。

Sobee 不只是一个启动器，还提供：

- HTML 窗口化运行
- JavaScript 脚本执行
- 自动恢复工作环境
- 护眼模式
- 快捷关闭屏幕
- 配置备份与迁移

## ✨ 功能特点

## 🚀 快捷启动管理

支持添加：

- `.exe` 程序
- `.lnk` 快捷方式
- 文件夹
- 文件
- UWP 应用
- 网站快捷方式

支持：

- 资源管理器拖拽添加
- 文件夹批量扫描
- 快速搜索
- 自定义图标
- 管理员权限启动

## 🧰 HTML 工具平台

普通 HTML 文件可以作为独立窗口运行。

例如：

- 番茄钟
- 计算器
- 密码生成器
- 音乐播放器
- 贪吃蛇
- 自定义网页工具

无需 Electron、Tauri 等桌面框架即可制作简单 Windows 工具。

## 📜 JavaScript 脚本支持

支持执行自定义 JavaScript。

可用于：

- 自动化操作
- 执行系统任务
- 创建个人工具
- 扩展功能

## ⚡ 自动恢复工作环境

支持：

- Sobee 启动自动打开
- Windows 开机启动自动打开
- 启动优先级设置

## 🎨 护眼与显示功能

提供：

- 护眼模式
- 快捷关闭显示器

关闭屏幕不会影响后台运行程序。

## 🖼 自定义图标

支持：

- PNG
- JPG / JPEG
- BMP
- GIF
- WebP
- ICO
- AVIF
- APNG
- SVG

无需转换 ico 文件。

## 🔄 配置管理

配置默认保存：

```text
%APPDATA%\Sobee\
```

支持：

- 自动备份
- 配置迁移

## 🔒 隐私

Sobee：

- 不需要账号
- 不提供云同步
- 不上传用户配置
- 不收集用户操作行为

网络请求主要用于：

```text
GitHub Release 更新检测
```
